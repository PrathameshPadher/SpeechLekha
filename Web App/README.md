# SpeechLekha Web Application

Run:
1. `npm install`
2. `npm run dev`
3. Open the Vite URL.

Routes:
- `/` = existing-style cinematic landing page
- `/app` = SpeechLekha application workspace

The Start Speaking CTA opens `/app`. The app includes microphone permission, a listening state, timer, simulated agent actions, transcript view, Markdown knowledge output, and knowledge files. Real Whisper/AI processing still needs your backend/API connection.
